# Early Alpha & Technical Preview Disclaimer (`v0.1.0-alpha`)

> **IMPORTANT NOTICE — EARLY ALPHA / TECH DEMO**
>
> **S.T.A.L.K.E.R. Anomaly 1.5.3 Studio (`v0.1.0-alpha`)** is an **early-stage Alpha build and technical preview (Tech Demo)**.
> It is published as an open experimental preview of a standalone 3D Level Inspector, 3D Object Placement Prototype, Visual Quest & Dialog Builder, and Direct `.db0` VFS Toolkit for **S.T.A.L.K.E.R. Anomaly 1.5.3 (64-bit Monolith Engine)**.

---

## 1. Current Scope & Limitations
- **Experimental Preview**: Workflows in `v0.1.0-alpha` are early prototypes designed to test direct `.db0` Virtual File System (VFS) reading, WebGL/Three.js rendering of Anomaly levels (`level`, `level.geom`, `level.cform`, `level.ai`, `level.spawn`), and visual Quest/Dialog authoring.
- **Work in Progress**: Features, UI panels, and project files may change or break between Alpha builds without backwards-compatibility guarantees.
- **Language Support**: English (`EN`) is the primary interface language. Russian (`RU`) is included as an **experimental (`Exp`)** preview with automatic English fallback.
- **Backup Reminder**: Although Anomaly Studio reads your base Anomaly 1.5.3 `.db0` archives in strictly **read-only** mode, always back up your `gamedata/` folder, savegames, and Mod Organizer 2 (MO2) profiles before testing exported `.db0` or `.zip` mods in-game.

## 2. Requirements & Warranty
- **Local Game Installation**: Point Anomaly Studio to your local installation of **S.T.A.L.K.E.R. Anomaly 1.5.3** so it can stream the `.db0` archives directly.
- **No Warranty**: This software is provided *"AS IS"*, without warranty of any kind, express or implied. Use at your own risk.
